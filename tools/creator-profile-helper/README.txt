itea 资料卡邮箱采集助手 1.0.0

本工具仅在你手动点击时读取当前 Instagram / TikTok 达人主页的公开资料卡。
有可见公开邮箱才保留，没有则跳过；无法读取页面时显示失败原因。
不登录、不获取 Cookie/密码、不访问关联网站、不发送邮件、不自动入库。

安装（Chrome / Edge）：
1. 将整个 ZIP 解压到一个固定目录，不要只解压单个文件。
2. Chrome 打开 chrome://extensions，或 Edge 打开 edge://extensions。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。
4. 正常打开一个达人完整主页，等待资料卡显示。点击此扩展，选择“读取当前主页资料卡”。
5. 如果找到邮箱，选择“复制结果”，返回 itea 系统“达人发现 → 粘贴资料卡结果”。
6. 预览后保存发现线索，需要正式入库时再勾选并确认导入达人库。

仅请求 activeTab、scripting 与 clipboardWrite 权限，用于读取当前页面和按你的点击复制结果。
没有服务器地址配置，没有跨站 API 请求、常驻后台任务、其他标签页扫描或历史记录读取。
公开邮箱未验证可投递性；主页上的 K/M 等简写只保留展示值，不写成精确粉丝数。
页面结构或权限变化可能导致读取失败。无法正常访问的主页仍无法采集。
这是手动资料卡采集辅助工具，不是自动关键词找达人服务。
