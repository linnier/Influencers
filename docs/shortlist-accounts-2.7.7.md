# 2.7.7 预选合作账号与保存提示

预选名单每个平台账号旁增加复选框，可按账号选择本次合作范围。旧预选默认沿用全部账号；取消不合作的账号后，点击该达人名下「保存合作账号」。选择可跨平台、多账号；未保存草稿会阻止准备邀约和导出，避免使用旧选择。可暂时保存空选择，但准备邀约前至少需要一个有效账号。

账号选择存储在现有项目预选工作流记录的 accountIds，修改权益或跟进状态时保留。服务端验证账号属于该达人、原记录版本及当前项目修改权限；不改达人库账号归属。邀约筛选、邮件预览和报名表初始账号沿用已保存选择；服务端再次校验，缺失或已失效账号不自动回退为全部账号。旧记录无 accountIds 时继续保留原全部账号行为。

Excel 增加拟合作平台／账号；平台账号表标明每个账号是否属于本次合作，仍保留全部原始账号、标签、邮箱和联系方式。

跟进状态及账号保存期间显示「正在保存」，同一达人相关控件暂时禁用，避免同时覆盖同一版本。保存完成后恢复；服务器或网络报错后显示行内错误及「重新读取」，不会永久锁住控件，也不会自动重复提交。重新读取确认账号已保存时清除对应草稿。

验证：真实 HTTP 的账号归属、角色／共同负责人、版本冲突、空账号与已邀约限制、重启持久化、邮件／报名初始账号；UI 覆盖保存中重绘、报错恢复、不自动重试、草稿与显式保存、导出字段；Chromium 走通账号选择、保存、刷新、状态标注、Excel 和实际邀约预览，未发真实邮件。原邀约、报名及预选筛选回归通过。
