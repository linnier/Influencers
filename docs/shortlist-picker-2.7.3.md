# 2.7.3 项目预选窗口

入口保持为「项目 → 项目预选 → 从达人库预选」。仅该窗口新增平台账号、主页链接、粉丝数、粉丝数上下限、快捷范围、只看已选以及分页。搜索支持达人名称、标签、地区、账号和主页链接。

平台与粉丝数范围必须在同一个账号上同时满足。同一达人按人去重；范围生效时排除粉丝数未知的账号，真实 0 仍按 0 处理。切换筛选、翻页及查看已选都保留勾选；每页50位、最多选择100位，避免原先只显示前100个匹配结果。账号按「平台、主页链接、粉丝数」逐行对应；缺链接时显示未填写，不猜测账号地址。主页链接仅允许 HTTP/HTTPS，并在独立标签页打开。

继续使用原 `/api/project-offers/add` 和版本检查。保存只加入预选，不发送邮件，不新建合作或 Post。所有样式局限于该窗口。项目列表、预算展示、工作区、邀约模板和后端权限未改。按用户取消修复的要求，未部署的 2.7.2 导航放行改动不包含在本次版本中；对应界面保持 2.7.1 行为。

验证：针对筛选/链接/未知数/跨页勾选/100人上限的测试，原方案及邀约流程测试，权限和真实 HTTP 测试，Chromium 桌面与375px手机窗口、实际加入预选及无合作/Post副作用检查。
