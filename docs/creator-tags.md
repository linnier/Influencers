# 达人合作标签（2.6.41）

达人库每个平台账号旁新增“打标签”，达人资料、项目合作管理及达人效果也提供入口。支持常用标签多选、自定义文字、删除标签、合作备注；同一达人ID的全部账号共用。旧标签、地区和备注继续保留在原档案，不按姓名或邮箱自动合并达人。

常用标签：内容质量差、配合度低、发布拖延、数据待核实、内容优质、配合积极。前四项以琥珀色提醒，正面标签以绿色显示，自定义标签为普通样式；分类仅由用户手动选择，不自动推断达人表现。

已有“标签”字段继续存储文字，支持顿号、逗号、分号和换行分隔；斜杠不拆分旧行业标签，大小写重复项只保留第一项，总长度不超过2000字。“合作备注”复用达人备注字段，打开时完整保留已有内容。标签与备注仅更新该达人档案，不改账号、合作、Post、费用或发券记录；关闭弹窗不保存。

达人库、项目合作管理、达人效果及邀约候选名单显示标签。已有搜索可按标签文字搜索。标签仅作团队提醒，不自动禁止或排除邀约。未将标签和备注加入邮件模板变量、邀约快照或公共报名数据。

复用原有达人编辑权限：管理员可编辑；负责人仅可编辑自己负责的达人，共享查阅账号不可修改。采用现有版本核对和保存接口；没有新建Lark字段或数据表，不需要准备字段。

验证：`npm run test:creator-tags` 使用 /creators 下真实本地HTTP/SQLite与JSDOM，覆盖多标签、自定义、去重、删除、转义、旧标签备注保留、只更新person、跨账号共享、资料/项目/邀约展示、取消不写入、查阅/非归属负责人限制、邀约及公共数据不包含内部标签备注。无真实邮件发送。
