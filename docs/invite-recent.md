# 避开近30天已合作达人（2.6.40）

入口：项目管理 → 进入项目 → 邀约与报名 → 筛选邀约。

新增“避开近30天已合作达人”，默认勾选，可取消以再次邀约。和“仅看尚未参与本项目的达人”、平台、粉丝数、搜索条件一起生效。切换时清空原选择，避免隐藏达人仍留在选择中；保留正在填写的权益、报名截止、邮件及拍摄/发布范围。

按新加坡日期计算连续30个自然日，包含今天和此前29天；比较真实合作确认日期，首尾均包含。跨所有项目检查同一个达人ID，任一关联账号近期确认合作即排除整位达人。已完成的合作计入；已取消、未选中、确认日期未知、无效日期和未来日期不算近期合作。不根据姓名、邮箱相同合并达人，也不用Post发布时间或发券日期推测合作日期。

准备邀约邮件预览的请求携带布尔值 `avoidRecent`。勾选时，服务器使用本次锁内重新读取的业务状态核对整个选中批次，任一达人近期已合作则整批拒绝，未创建部分邀约。明确取消勾选可再次邀约。旧客户端未传参数时保留原有行为。现有同项目邀约去重与重复邮箱检查继续生效。

该条件用于新建定向邀约候选名单和准备预览，不影响已存在的待发邀约、公开报名链接或报名审核。没有增加自动发信，也没有更改原始合作记录。准备预览本身不发送邮件。

验证：`npm run test:invite-recent` 覆盖UI默认状态、近30天边界、跨年闰月、跨项目多账号、未知与取消记录、组合筛选、切换清空选择与保留表单、页面旧数据被服务端拦截、整批不部分写入、显式取消和旧客户端兼容。测试使用本地合成数据，不调用真实邮箱。

本版本同时修正项目列表不应显示公共Post日期控件的问题：列表和合作执行页隐藏并停用日期条件，返回总览或Post数据后恢复已选范围。
