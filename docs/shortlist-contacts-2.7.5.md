# 2.7.5 补充预选导出邮箱和联系方式

「导出全部预选」及「导出已勾选」的两个 Excel 工作表均增加「邮箱」「联系方式」两列，取自达人库 `email` 和 `contact`。完整保留多邮箱、电话、WhatsApp／微信等原始文本，前导0与国际区号加号不会被转为数字；未填写时保持空白。主页链接列及费用列的对应位置、格式和筛选范围随列位移同步更新。

达人标签、方向、平台、粉丝数、方案权益等原有导出字段仍保留。既有导出及联系方式权限未调整，查阅账号仍不能导出。名单页面仅更新导出字段说明，其他页面和流程保持。

验证包含实际 Excel 写入／读取，两个工作表的完整邮箱与联系方式、空白缺失值、标签、费用与超链接，及现有权限检查；真实浏览器分别下载全部和已勾选文件，核对邮箱、WhatsApp文本与多平台对应关系。旧文件不会自动变化，更新网页后需重新导出。
