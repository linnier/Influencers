# 2.7.4 项目预选导出

「项目预选」名单直接展示达人全部标签／内容方向、地区、所有平台账号、有效主页链接及对应粉丝数；多平台账号与粉丝数逐行对齐。保留原方案／权益与操作，支持全选当前分组。布局仅作用于该名单，手机下按达人分段显示。

「项目预选」增加「导出全部预选」和「导出已勾选」。下载标准 `.xlsx`，内容取自当前页面已载入的资料；不增加 Lark 请求，不写数据，不发邀约。全部导出不受当前合作分组筛选影响，已勾选导出只包含实际勾选的人；已经进入邀约流程或移出的记录不包含在预选导出中。

Excel 包含两个工作表：

- 「预选达人」：每位达人一行，保留达人库全部原始标签／内容方向，列出地区、达人负责人、平台、付费／互惠／待商议合作类型、费用方式与币种、固定费、内部预计费、权益成本、约定券数、中英文权益及发布要求、截止日期、合作方案、是否个人调整和内部预选备注。
- 「平台账号」：逐账号列出关联达人及完整标签、平台、账号、可点击主页链接和粉丝数。费用仅放在达人表，避免多账号重复计算。

空白费用和粉丝数表示未记录，真实0保留；项目默认截止日期会带入。导出受既有账号导出权限和当前项目管理权限限制，包含共同负责人；查阅账号无导出入口。Excel 文本保持文本类型，主页超链接仅允许 HTTP/HTTPS，文件名过滤不合法字符。其他页面、预选筛选窗口、邀约模板及服务端权限规则保持不变。

验证：实际 SheetJS 写入再读回，检查全部标签、内容方向、合作类型、分组选中范围、多账号、不重复费用、空白和0、截止日期、文本及链接；检查权限变化与共同负责人。Chromium 在正式服务挂载路径下载全部和已勾选两个文件，读取核对标签、手机排版以及导出前后资料不变。原方案/报名/邀约、预选窗口和账号权限回归通过。
