# 已投流 Post（2.6.37）

## 使用入口

- 在近期项目总览或项目内的「项目总览」中，点击对应币种的「投流费用」卡片。
  页面进入 Post 列表，自动勾选「仅看已投流」，并选择卡片币种。
- 在项目的 Post 数据列表中，也可直接勾选「仅看已投流」。
- 项目、平台、负责人和搜索条件保持原范围；点击「查看全部 Post」只清除投流和币种筛选。
- 切换项目时清除币种限制，避免新项目使用另一币种时出现误导的空列表。

仅看已投流时，列表直接展示投流费用、投流阅读、投流曝光、投流互动，保留笔记链接、
详细数据和原有编辑入口。全部 Post 模式保留原有总阅读、曝光、互动和合作价格，并增加
直接可见的投流费用。数量、费用小计、费用待补提示覆盖筛选后的全部记录，分页每页 30 篇。

## 判断和金额

投流费用、投流阅读、投流曝光、投流互动任意一项为大于 0 的数值，即认为已有投流证据。
只有真实 0 或未知值的记录不会自动归为已投流；「未记录投流」不等于确认未投流。

有投流数据但缺失费用的 Post 仍显示，并计入「费用待补」。费用未知不会填成 0。
金额按 Post 币种、其次项目币种归组分别累计，不换汇，不把总指标与投流明细重复相加。
没有已投流记录的费用卡片不可点击。

只读账号可点击卡片、筛选、查看明细和翻页，仍不可编辑或录入。筛选和跳转不会写入
业务数据、变更费用、发券或发送邮件。无需新增 Lark 表格字段。

## 部署

更新到本版本提交后，只需重启现有 itea-creator-migration 容器。原 /creators/ 挂载、
Nginx、HTTPS、邮箱授权、自动催促开关和数据挂载均保持现有配置。
