# 邀约报名：拍摄和发布日期（2.6.36）

在「项目管理 → 进入项目 → 邀约与报名 → 筛选邀约」的「报名表 · 拍摄与发布安排」中填写：

- 拍摄开始日期、拍摄结束日期。
- 发布开始日期、发布结束日期。

例如拍摄范围为 2026-11-01 至 2026-11-10，发布范围为 2026-11-05 至 2026-11-15。
随后检查并预览邮件，或创建公开报名链接。范围跟随每一条新邀约保存；创建本身不发送邮件。
当前项目中的筛选重绘会保留尚未提交的范围草稿；浏览器刷新前需完成新邀约创建。

达人报名表增加中英双语「计划拍摄日期」「计划发布日期」。设定某项范围后，对应日期必填，
开始日和结束日都可选择。日期输入框与服务器都会校验范围；发布日期不能早于拍摄日期。
范围必须填写完整且起止正确，并允许至少一种拍摄后发布的有效组合。

不设置范围的日期可以留空；未设置限制的旧邀约继续接受没有日期的旧客户端提交。
本版本按用户要求只影响新建的邀约和新建的公开报名链接，不回写旧邀约范围或历史报名。
旧版 Render 链接仍按旧版本表单处理，不会自动要求新增日期。

计划日期保存在报名工作流记录中，在报名审核列表、单人审核弹窗、批量确认弹窗和已确认
合作名单 CSV 中显示。不需要新增 Lark 多维表格字段。计划日期不会生成 Post、替代实际
发布日期、修改下次跟进日期或更改券数、费用。

部署到现有 /creators/ 服务时，拉取并检出对应提交后重启 itea-creator-migration 容器即可，
原有 APP_BASE_PATH、PUBLIC_BASE_URL、DISABLE_AUTOMATIC_REMINDERS 和数据挂载保持不变。
不需要重新配置 Nginx 或邮箱授权。检查 /creators/health 后刷新浏览器。
