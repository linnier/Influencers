# 项目自定义合作权益文案（2.6.42）

入口：项目管理 → 进入项目 → 邀约与报名 → 通知设置 → 项目要求。

在拍摄与发布要求之前新增“中文合作权益”和“Collaboration benefits（英文）”文本框，最多各2000字，要求中英文成对填写或同时留空。适合填写饮品券、冰淇淋、礼品等项目共用说明。优惠券使用说明继续单独保存，原有内容不会自动搬移或删除。

填写并保存后，邮件中的 `{{合作权益}}` 和 `{{合作权益英文}}` 优先使用自定义内容；同时留空则恢复按金额与券数自动组合的原逻辑。原有 `{{合作金额}}`、`{{券数量}}`、`{{约定券数}}` 等数值变量保持原义。新建邀约、合作确认和发券通知均通过同一变量函数带入；其他邮件模板也可使用这两个变量。没有变量的自定义模板不会被自动插入权益段落。

“预览四类邮件”使用当前未保存输入，不发送邮件；“使用已确认的标准模板”保留自定义权益、要求及使用说明。旧设置读取时补空值，旧客户端保存时保留已有权益字段；没有自动迁移或覆盖用户的邮件模板。历史已生成的邀约、通知正文快照保留，变更用于之后生成的邮件。

该字段仅是项目共用文案，不改变合作金额、券数、实际发券台账、预算或成本。不新增Lark字段或表，保存在现有工作流通知设置JSON中。公开报名页的结构化金额/券数仍使用原邀约权益数值，不能由说明文案推算饮品券或礼品数量。

测试：`npm run test:custom-benefits` 覆盖输入位置、双语校验与长度、未保存预览的转义及不发送、标准模板保留字段、真实工作流处理器的保存/邀约/确认/发券渲染、清空恢复自动组合、旧客户端兼容、旧邀约快照不变和原始费用/券数不变。邮箱调用均为本地桩。
