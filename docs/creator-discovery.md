# 达人发现（2.6.46）

保留近期项目总览、达人库、项目管理、达人入库，只追加「达人发现」入口。
发现记录独立存放于已有协作工作流，只有确认导入才新增正式达人及平台账号；不修改邮件、合作、Post 或现有入库流程。没有生产演示数据或种子名单。

## 功能与真实采集范围

- 粘贴完整 Instagram / TikTok 主页，每批最多5条、同时读取2条。只尝试公开 HTTPS 页面；不使用登录 Cookie、不绕过验证码或平台拦截，也不发送邮件。
- 解析与目标账号对应的公开 JSON 或 meta 简介，提取公开邮箱与明确的整型粉丝数。简略的 12.3K 等粉丝展示不换算为已核实精确值。
- 简介包含公开关联网站且平台简介未提供邮箱时，可读取该关联网站可见文字中的邮箱，并保存来源及短摘录。
- 登录页、403、超时或无法核对账号时保留「未获取」与原因。刷新失败不抹掉原有资料；手动补充的字段也不会被采集覆盖。
- 可手动添加/补充公开资料；填写邮箱必须保留来源网址，并带手动补充及待核实说明。
- 关键词、平台、地区、资料状态、粉丝档位、自定义上下限、未知粉丝数、收藏筛选；筛选针对已保存的发现记录。暂未接入跨平台关键词搜索或付费数据服务，不能保证平台主页可读取或取得邮箱。
- CSV 导出含来源，空粉丝数保留为空；导出防止公式注入。
- 选中后设置负责人、预览入库、确认新增。重复平台账号跳过；相同邮箱需人工核对，不自动合并、覆盖或追加他人账号。

## 权限与保存

查阅账号不可查看商务联系方式或操作发现模块。负责人只看自己的发现记录、导入到自己的负责人名称；管理员可查看全部发现记录并指定入库负责人。
所有修改使用既有登录及同源 Origin 校验。发现保存、入库沿用协作工作流锁；正式写入使用现有 state 校验、权限和版本检查。预览包含发现资料摘要与正式库版本，两者变化时重新核对。并发确认只会成功一次；重复导入按平台账号跳过。

记录上限为每个可见工作区1000条；单次确认入库最多30位。HTTP 服务收到未知结果应先刷新核查，不应反复点击。

公开页面读取限制为 HTTPS、最多3次重定向、总超时10秒、响应最大1MiB。连接时检查并绑定 DNS 地址，拒绝内网、回环、保留网络、IP 网址、显式非默认端口及凭证。关联网站也使用同样边界，支持纯文本/HTML/JSON。不缓存完整页面或平台凭证。

## 验证

`npm run test:discovery`：解析、网络边界、未知/零粉丝数、持久化、来源、失败保护、粉丝筛选、入库/重入库、权限隔离、同源、版本变化与并发确认。
另运行现有权限、管理员界面、子路径和启动检查，以及 Chromium 在 `/creators/` 的实际页面/导入/重载/手机测试。
这些测试使用隔离 SQLite、合成账号和模拟公开页面；没有触碰生产达人、Lark 或真实邮件。Instagram/TikTok 实际采集成功率尚未在生产服务器验证。
