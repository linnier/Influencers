# 达人发现（2.6.47）

保留近期项目总览、达人库、项目管理、达人入库，只追加「达人发现」入口。
发现记录独立存放于已有协作工作流，只有确认导入才新增正式达人及平台账号；不修改邮件、合作、Post 或现有入库流程。没有生产演示数据或种子名单。

## 功能与真实采集范围

- 粘贴完整 Instagram / TikTok 主页，每批最多5条、同时读取2条。只尝试公开 HTTPS 页面；不使用登录 Cookie、不绕过验证码或平台拦截，也不发送邮件。
- 解析与目标账号对应的公开 JSON 或 meta 简介，提取公开邮箱与明确的整型粉丝数。简略的 12.3K 等粉丝展示不换算为已核实精确值。
- 简介包含公开关联网站且平台简介未提供邮箱时，可读取该关联网站可见文字中的邮箱，并保存来源及短摘录。
- 登录页、403、超时或无法核对账号时保留「未获取」与原因。刷新失败不抹掉原有资料；手动补充的字段也不会被采集覆盖。
- 可手动添加/补充公开资料；填写邮箱必须保留来源网址，并带手动补充及待核实说明。
- 在线搜索和已保存结果筛选分开。在线搜索通过 Brave Search 正式接口按关键词、平台与地区检索新账号；本地筛选不调用服务。连接配置完成前显示接入提示，不把未配置、接口失败当成0条结果。不能保证平台主页可读取或取得邮箱。
- CSV 导出含来源，空粉丝数保留为空；导出防止公式注入。
- 选中后设置负责人、预览入库、确认新增。重复平台账号跳过；相同邮箱需人工核对，不自动合并、覆盖或追加他人账号。

## 权限与保存

查阅账号不可查看商务联系方式或操作发现模块。负责人只看自己的发现记录、导入到自己的负责人名称；管理员可查看全部发现记录并指定入库负责人。
所有修改使用既有登录及同源 Origin 校验。发现保存、入库沿用协作工作流锁；正式写入使用现有 state 校验、权限和版本检查。预览包含发现资料摘要与正式库版本，两者变化时重新核对。并发确认只会成功一次；重复导入按平台账号跳过。

记录上限为每个可见工作区1000条；单次确认入库最多30位。HTTP 服务收到未知结果应先刷新核查，不应反复点击。

公开页面读取限制为 HTTPS、最多3次重定向、总超时10秒、响应最大1MiB。连接时检查并绑定 DNS 地址，拒绝内网、回环、保留网络、IP 网址、显式非默认端口及凭证。关联网站也使用同样边界，支持纯文本/HTML/JSON。不缓存完整页面或平台凭证。

## 在线搜索连接（2.6.47）

1. 管理员在「达人发现」点击「连接搜索服务」。
2. 打开 `https://api-dashboard.search.brave.com/` 注册并按官网当前规则开通 Web Search、创建 API Key；费用与额度以官网为准。系统不代为注册、购买方案或创建密钥。
3. 在系统连接弹窗中填写密钥，每日调用上限默认20次，可设1至200次；保存时不调用搜索接口。
4. 可点击「测试连接（1次调用）」，或直接在线搜索。测试不保存候选或导入达人。

配置使用原工作流存储中的独立 `discovery-search-config` 类型，密钥以 AES-256-GCM 加密，密钥材料来自原有 `LARK_APP_SECRET` 或 `TEAM_PASSWORD`，使用独立 AAD；API不返回密钥、密钥前缀或密文。可在服务器设置 `BRAVE_SEARCH_API_KEY`，这时网页不能覆盖环境变量中的密钥。更换加密材料后需要重新连接搜索。

每日全局调用次数按新加坡日期存放 `discovery-search-usage` 记录，在发请求前持锁计数；失败尝试也计数，以保守限制调用量。只有管理员可修改配置、暂停或测试；负责人可使用已配置服务，但不能读取密钥或改配置；查阅账号不能使用服务。配置预算上限不是服务方账单承诺，仍需在服务方设置适合的额度。

搜索固定向 `https://api.search.brave.com/res/v1/web/search` 发送请求，密钥只在头部，禁止跟随重定向。每次搜索最多1次服务调用、20条网页结果，无自动翻页；请求超时20秒，响应上限3MiB。页面不提供更换服务主机的字段。

只把可识别的 Instagram / TikTok 完整主页作为候选，跳过 Post、非主页、重复项及不同于所选平台的结果。搜索条件中的地区只表示查询相关性，不能作为达人常驻地区事实写入 `region`。内容简介/邮箱和粉丝数保留「搜索索引、非实时、待核实」来源。对索引中 3.2K 等简写保留估算标记；`fansIndex` 与原 `fans` 分开，导入时索引数字不写成已记录粉丝数，而是随来源记入备注。

在线结果有已知粉丝数区间和缺失粉丝数两个视图。未知粉丝数不会填0；零个符合区间但有未知候选时，页面显示待核实候选并明确两类数量。已有人工补充或主页采集资料不因重新搜索被覆盖；新索引来源只补充，失败或合法空结果不删除已保存资料。

新增 `npm run test:discovery-search` 验证无配置提示、加密/权限、固定服务地址、查询条件、计数、结果归一化、来源与粉丝字段、失败保护及 UI 搜索状态。Chromium 验证了实际页面与加密配置保存、筛选、导入；外部 Brave 响应为合成测试数据，未使用真实密钥、未发生真实服务调用。生产服务连通性需管理员配置实际密钥后验证。
