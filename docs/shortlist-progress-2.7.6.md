# 2.7.6 预选沟通进度与邮箱搜索

预选名单中每位达人名称下新增「跟进状态」下拉框：未标注（可清除）、已询价、洽谈中、权益确认、高意向合作。选择即保存到当前项目该达人的预选工作流记录；刷新及服务重启后保留。名单可按跟进状态筛选，Excel 的两张表均带入跟进状态。

这是预选沟通标注，与报名、邀约发送、合作阶段、费用及发券状态独立。「权益确认」不会自动确认正式合作。修改方案／个人权益不会覆盖标注，移出后再加入同项目保留原标注。已经进入邀约流程或已经移出的预选不接受此入口的状态修改。

写入沿用现有项目负责人权限与写锁，管理员及当前项目共同负责人可操作；查阅账号及其他项目负责人不能写入。请求校验原记录版本，避免覆盖同时修改；记录标注人及时间。成功返回更新记录，页面可直接更新，不必追加全库读取。现有预选没有标注时按未标注显示，无需新增 Lark 表或字段；备份自动包含工作流字段。

同时修复「从达人库加入项目预选」搜索遗漏邮箱的问题：支持完整／部分邮箱、忽略大小写及首尾空格，包含多邮箱字段；继续与平台、粉丝数和只看已选条件共同生效。

验证：真实 HTTP 覆盖四种标注和清除、版本冲突、权限／共同负责人、重启、移出／邀约限制及业务数据不变；UI 验证原有邀约报名流程、状态筛选和 Excel；Chromium 实测邮箱查询、选择即保存、刷新保留、含状态／邮箱／标签的下载和手机排版。
