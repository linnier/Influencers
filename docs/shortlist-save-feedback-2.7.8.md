# 2.7.8 修正预选保存反馈

修复跟进状态保存期间的两处显示问题：重新绘制名单时会显示回旧状态，以及通用「正在保存」提示错误地放在合作账号栏。现在保存期间始终显示刚选择的状态，并在状态框下方明确显示「正在保存跟进状态：…」；只有保存合作账号才在账号栏显示账号保存提示。

状态保存不禁用账号复选框，也不创建账号草稿或发送账号保存请求；同一记录仍按原版本机制防止并发覆盖。保存错误在对应字段区域显示，保留手动重新读取入口。保存尚未完成时不导出旧状态，完成后正常导出。权限、邮件、费用、实际账号选择与后端接口未改变。

验证覆盖延迟响应期间重绘仍显示新值、请求仅含 progress 且没有 accountIds、账号选项不受影响、网络／服务器失败恢复以及独立账号保存；真实 Chromium 延迟保存响应验证上述显示、实际请求和最终数据。原权益、邀约报名与 Excel 回归通过。
