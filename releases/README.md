# 2.4.11 累计升级包

[下载升级包](itea-creator-hub-upgrade-2.4.11.zip)

itea创作者管理 2.4.11 单条笔记自动记账累计升级
适用已有2.4至2.4.10系列网站，包含此前全部补丁。

安装：
1. 原网站运行的黑色窗口Ctrl+C停止网站。
2. 解压进入能看到install-update.mjs的内层文件夹，在地址栏输入cmd并回车。
3. 运行 node install-update.mjs；提示时粘贴原itea-creator-hub完整路径。
4. 回到原网站目录运行 node setup-local.mjs，网页Ctrl+F5。
保留.runtime配置、密码与业务记录；自动备份旧代码，可用备份目录restore.mjs回滚。此次不增加Lark字段，无需重新导入Excel。

项目列表保留项目、负责人、预算/币种、参与达人、已发布数量和创建项目入口。
进入项目后分为：
合作管理：默认列表，按报名/沟通、已确认待发布、执行中、已完成、取消/未选中筛选，展开各平台任务，修改状态、跟进与合作资料。
Post数据：每篇笔记录入、编辑、核对阅读/曝光/互动/价格。展开查看互动与费用明细。无账号或无合作时可在录入中补建；已知itea/邮箱可关联已有达人。
达人效果：只展示有效合作中已有Post的达人，汇总各平台数据。支持效率卡/列表，阅读/互动从高到低、CPM/CPE/价格从低到高、最近发布或默认排序。未知数据排后，币种分开。
项目总览：集中汇总项目数据、预算、合作费、投流费、券包费。
已报名未合作与已合作达人改为合作管理状态筛选，不再重复设置页面；跨项目Post数据、项目报名及批量导入入口保留。

互动优先自动合计点赞+评论+收藏+分享，四项不完整时采用平台报告总数，每篇只计一次。真实0填写0，未知留空。
达人合作价格来自Post合作费，CPM=对应合作价格/曝光*1000，CPE=对应合作价格/互动；仅使用具备价格和对应分母的Post，标注覆盖篇数。项目费用另计投流及券费；券数*SGD3，币种分开不换算。
达人资料可绑定已有账号，账号及项目合作同步统一归属，Post和费用保留。

已通过正式页面DOM交互、报名确认与首篇Post进入效果、Post编辑自动重算、新账号补建合作、账号绑定与批量保存、Excel多平台导入/恢复、费用与币种、模拟Lark关联、服务端校验及安装备份回滚测试。尚未在用户Windows电脑或真实Lark环境验证本包，未做真实浏览器视觉检查。

筛选修复：进入项目自动清除上一个页面的平台、关键词、负责人及合作状态筛选，展示全部平台。详情明确列出项目参与人数、当前筛选人数、Post数和筛选范围；主动筛选后可点击“查看项目全部数据”。不修改Lark业务记录，不重新导入Excel。

单条笔记自动记账：
一笔合作只有1条选中笔记时，合作费和发券数量自动记在本条，不显示费用记账选择框。只有多条选中笔记才保留选择。取消勾选到只剩1条自动记账，重新勾选多条恢复选择；所有合作都是单条时，顶部批量记账平台也隐藏。不会重复计费或发券。
已验证单条和多条混合、动态勾选、费用与券数只记一次、原有账号搜索和导入中断恢复。
