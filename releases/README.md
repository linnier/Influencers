# 2.4.12 累计升级

[下载升级包](itea-creator-hub-upgrade-2.4.12.zip)

itea创作者管理 2.4.12 累计升级包

当前导入页面还有逐条匹配时：不要刷新、关闭、重新选文件。
1. 保持浏览器原导入页打开。在运行网站的黑色窗口按 Ctrl+C 停止后台。
2. 解压本升级包，进入内层含 install-update.mjs 的文件夹，地址栏输入 cmd 回车。
3. 运行 node install-update.mjs，按提示粘贴原 itea-creator-hub 文件夹路径。
4. 回原网站文件夹运行 node setup-local.mjs。
5. 回到原浏览器导入页，点击“检查并预览”，确认匹配仍在，再点击导入。已保存内容会跳过。
6. 导入成功后才 Ctrl+F5 刷新，启用新版草稿与发券数量。
若再遇错误，保持页面，先备份匹配，不要清空重来。

本版修复：分批写入基于每批返回的最新状态；后端兼容旧导入页缺少的默认字段，避免已保存记录被误计为新修改。保留每批20项修改保护，长表自动分批。新页面自动在当前浏览器保存匹配草稿，并可下载/恢复JSON草稿。换设备或清浏览器缓存前请下载草稿；恢复时选择原Excel及相同工作表。

达人效果卡及合作列表新增发券数量：汇总当前达人、项目范围的Post券数；只累加有填写的数值，显示填写覆盖率；未填不当作0。跨平台整笔券数仍只记在指定Post，不重复分配。

应急备份（可选，在原页刷新前做）：打开“应急备份匹配命令.txt”，复制全部代码，在原导入页按F12，选择Console控制台，粘贴运行，下载匹配JSON到本机。此命令不联网，不修改网站记录。升级后若需要恢复，选原Excel和相同工作表，再用“恢复匹配草稿”选择此JSON。

只更新代码，保留.runtime、Lark配置、团队密码及业务记录，不需要新增Lark字段。原代码备份位置由安装程序显示；停止网站后运行备份目录的 node restore.mjs 可回滚。本地模拟导入、旧页兼容、草稿恢复、安装回滚测试通过；实际Lark数据由安装后导入验证。
