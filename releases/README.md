# 2.4.7 累计升级包

[下载升级包](itea-creator-hub-upgrade-2.4.7.zip)

itea创作者管理 2.4.7 达人资料绑定已有账号升级
适用已运行2.4至2.4.6的网站。本包包含之前全部补丁：按达人合并展示、互动量自动计算、Post编辑和直接录入、多账号及搜索。

安装：
1. 原网站运行窗口Ctrl+C停止网站。
2. 解压进入能看到install-update.mjs的内层文件夹，地址栏输入cmd，回车。
3. 运行 node install-update.mjs；提示时填写原itea-creator-hub文件夹完整路径。
4. 原网站文件夹运行 node setup-local.mjs；网页Ctrl+F5。
配置、密码与Lark业务记录保留，自动备份旧代码，备份目录restore.mjs可回滚代码。本次不新增Lark字段，不需要重新导入Excel。

绑定操作：
1. 在合作达人列表或达人库，点击要保留的达人名称。
2. 达人资料中，新增平台账号旁点击“绑定已有平台账号”。
3. 按达人名称、平台账号、itea账号或邮箱搜索，可筛选平台，勾选需要关联的已有账号。
4. 核对预览显示的平台、账号和目前所属达人；确认选中账号都属于当前达人，勾选确认，保存。
选中账号及所有项目合作的达人归属同步更新，合作列表重新按达人汇总。平台用户名、粉丝数、主页、合作状态、负责人、确认日期、Post、费用和券数保留。未选择的账号保持原归属。
使用当前达人档案的姓名、邮箱等基本资料；原档案资料保留，不自动覆盖资料或删除记录。不按同名自动合并。
批量绑定按账号及关联合作完整分组，每批最多20条变更。如果单账号关联超过19个项目，会在写入前拦截并提示维护处理。
写入失败可能部分保存，刷新核查后重新勾选尚未绑定的账号，不自动重试。

已验证搜索和选择保留、确认前不写入、归属同步、三平台合并、跨项目关联、21个账号及63条合作分为5批完整保存、模拟Lark文本ID及关联字段更新、Post及费用保留、原有录入编辑与自动互动量回归、服务端及安装回滚。尚未在用户Windows或真实Lark环境验证。
