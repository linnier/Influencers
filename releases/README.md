# 2.4.13 服务器自动分批修复

[下载累计升级包](itea-creator-hub-upgrade-2.4.13.zip)

itea创作者管理 2.4.13 累计修复

本版修复后端仍按整次请求限制20项修改的问题。现在由服务器自动按每组最多20项顺序写入，不再要求你手工取消勾选或拆成20条。写入前先检查全部字段及关联，网络失败即停止，不自动重试；同一请求最多2500项修改。保留2.4.12的发券数量与匹配草稿及此前补丁。

当前浏览器原导入页还有匹配时：不要刷新、关闭或重新选择Excel。
1. 保持原浏览器页打开，仅在运行网站的黑色窗口按 Ctrl+C。
2. 解压本包，进入内层含 install-update.mjs 的文件夹，地址栏输入cmd并回车。
3. 运行 node install-update.mjs，按提示输入原 itea-creator-hub 文件夹完整路径。
4. 回原网站文件夹运行 node setup-local.mjs。
5. 在另一个新标签页打开 http://192.168.0.84:3000/api/connection，看到 build 为2.4.13且 automaticWriteBatches为true，才说明新后台已生效。原导入页不要刷新。
6. 回原导入页，点击“检查并预览”，核对原匹配，再点“导入检查通过的记录”。已导入Post会跳过。等待完成，不连续重复点击。
7. 导入成功后才Ctrl+F5刷新，启用新版发券显示及草稿功能。

如果仍报错，保留原页，发当前完整错误及新标签页的build值。可选：在原页F12的Console运行“应急备份匹配命令.txt”全部代码，将匹配草稿JSON保存在本机。代码不联网、不修改业务数据。新版恢复需先选原Excel及相同工作表，再选恢复匹配草稿。

升级只覆盖代码，保留.runtime、Lark配置、团队密码及数据，不需要新增字段。代码自动备份，可停止网站后运行备份目录的node restore.mjs回滚。已通过模拟Lark的35项修改、跨20项边界中断、继续保存去重、前置字段校验及安装回滚测试；真实Lark导入需安装后核验。
