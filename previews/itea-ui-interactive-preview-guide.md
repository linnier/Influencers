# itea 网站交互预览

基于 2.6.28，共 36 个页面及弹窗。下载 `itea-ui-interactive-preview.html`，使用新版 Chrome 或 Edge 打开。

预览使用虚构数据，保存、审核、发券和邮件均在浏览器内模拟，不连接正式网站或 Lark。管理员、负责人、查阅账号以及电脑/手机视图均可切换。

本版包括：精简总览及字段文案、展开统计规则、同一表单添加其他平台的发布链接/浏览量/总互动量，以及简化合作状态。

正式版本中，多平台回填一次提交、一同审核，审核通过后生成独立 Post。对应平台账号不存在时，审核人员可选择或补充账号；发券及合作费用不会复制到其他平台。

预览文件上传到仓库并不代表 Render 已部署。正式网站须在 Render 部署最新提交后生效。
