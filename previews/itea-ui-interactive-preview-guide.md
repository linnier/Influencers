# itea 网站交互预览

基于 2.6.26 前端界面的独立演示版，含 36 个页面/弹窗入口。

[下载交互预览 HTML](https://github.com/linnier/Influencers/raw/refs/heads/main/previews/itea-ui-interactive-preview.html)

下载后使用新版 Chrome / Edge 打开 HTML 文件即可，不需要安装或启动后台。如果 GitHub 显示源码，请使用 Download raw file 保存为 .html 后打开。

- 左侧目录可切换项目、达人库、邀约、报名审核、Post、发券、导入、账号权限及博主端表单。
- 顶部可切换电脑/手机视图和管理员/负责人/查阅角色。
- 可以操作弹窗和表单，编辑回填、模拟发券、提交申请、导入演示 Excel、修改项目名称等。表单演示验证码：123456。
- 演示记录保留在当前打开的页面内，可点击“重置演示数据”恢复初始状态。所有数据虚构，不连接 Lark、Render、真实邮箱或生产数据；不要输入真实账号密码或客户资料。
- 可以用“复制当前位置”记录页面编号，再描述 UI 修改需求，例如“22 审核回填：把链接移到顶部”。

此 HTML 是用于界面评审的浏览器本地模拟，实际网络、邮件投递、Lark保存与服务端权限仍以正式系统为准。线上网站不因本预览文件改变。
