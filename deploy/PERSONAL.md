# Windows 个人使用版

只需要你自己的电脑，不需要服务器、域名、Docker、WSL 或 Codespaces。

1. 下载最新 ZIP，右键选择「全部提取」，进入包含 `start-personal.cmd` 的文件夹。推荐放到本机用户目录下，路径尽量短，例如 `C:\Users\你的用户名\Influencers`。
2. 双击 **start-personal.cmd**。第一次会下载校验过的官方 Node.js 24 便携版、安装组件并构建页面，需要联网和等待；不需要管理员权限。
3. 准备完成后自动打开浏览器。以后仍然双击同一个文件，组件和页面不变时无需重新安装或构建。

保持启动窗口打开。关闭窗口或关闭电脑会停止运行，数据会保留。

数据位于 `%LOCALAPPDATA%\StarBridge\data\influencers.sqlite`，更换安装文件夹不会切换或清空档案。首次使用是空数据库，进入「达人资源库」点击「导入 Excel」，选择你原来的 `itea博主清单.xlsx`。此功能识别 XHS、Instagram、Tiktok 工作表，合并重复账号，保留原始备注和联系方式；重复导入会跳过已有账号，不覆盖手动编辑的档案。

系统只监听本机回环地址，适合你自己使用，没有额外登录步骤。运行时可断网；Excel 在本机解析，名单不上传到 GitHub。下载的源码 ZIP 不包含真实名单。

支持 64 位 Windows 10/11（Intel/AMD 或 ARM64）。若启动失败，保留窗口，发送其中的报错截图；不要重新安装 Docker 或启用虚拟机。

备份：关闭启动窗口、确认系统停止后，将数据目录整体复制到你的私有备份磁盘；如果存在 `-wal`、`-shm` 文件，必须一并复制。也可在系统内导出达人 CSV，但 CSV 不包含项目及跟进记录，不能代替完整备份。
